mimi rclone

This covers "mimi rclone", the Google OAuth app used by the maintainer's own home server to back up its data to the maintainer's own Google Drive. It is for personal use only and is not offered to anyone else.

The app requests only the Google Drive scope drive.file: access to files the app created, plus any file the user explicitly opens with or shares to the app. It has no access to the rest of the Drive. In practice it only touches its own backup folder. Backups are encrypted on the server before upload.

No data is collected, sold, shared with third parties or used for any purpose other than that backup.

content

"content" is the Google OAuth app the maintainer's own publishing tool (JakobMelchard/content) uses to upload videos to the maintainer's own YouTube channels and read their statistics. It is for personal use only and is not offered to anyone else.

It uses the YouTube Data API to upload videos, set thumbnails, manage the channels' playlists and post a first comment, and the YouTube Analytics API to read view and retention numbers for those channels. OAuth tokens stay on the maintainer's home server. No data is collected, sold, shared with third parties or used for any other purpose.

Questions: open an issue at github.com/JakobMelchard/JakobMelchard.github.io.
